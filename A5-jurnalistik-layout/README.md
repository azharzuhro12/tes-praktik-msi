# A5 — Jurnalistik Data & Tata Letak Majalah 1 Halaman (SIMULASI)

Folder ini berisi naskah artikel jurnalistik 260 kata faktual dan tata letak editorial 1 halaman majalah siap cetak/PDF.

## 📁 Berkas:
- `A5-N01-artikel.md`: Naskah artikel jurnalistik lengkap (tepat 260 kata, batas 250–350 kata).
- `A5-L01-layout.pdf`: Tata letak majalah 1 halaman format PDF (2 kolom editorial, pull-quote, boxout formula).
- `A5-L01-layout.html`: Kode tata letak editorial modern HTML & CSS.
- `A5-L01-layout.png`: Gambar render tata letak majalah.
- `chart_rekap.png`: Infografis grafik batang perbandingan waktu proses (120 vs 90 menit).
- `make-a5-chart.py`: Skrip Python matplotlib pembuat grafik perbandingan.
- `test-a5.js`: Skrip uji otomatis jumlah kata dan verifikasi integritas klaim.
- `A5-U01-hasil-uji.txt`: Log hasil kelulusan uji otomatis.
